# e-plantShopping

e-plantShopping is a React-based online plant shopping application.

## Project Description

This application allows users to browse different categories of plants,
view plant images and prices, add plants to a shopping cart, update
quantities, remove items, and calculate the total cart cost.

## Features

- Browse plants by category
- Add plants to the shopping cart
- Increase and decrease quantities
- Remove plants from the cart
- View individual item totals
- View the overall cart total
- Continue shopping
- Responsive user interface
